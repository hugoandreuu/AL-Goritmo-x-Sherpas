# Preguntas para el canal de mentores (Discord)

> Solo se pegan las frases en negrita. El canal es compartido con otros equipos: no contar la idea. Las líneas "→" son para el equipo.

1. **¿Basta con construir la experiencia para un solo caso, o esperáis ver los cuatro?**
   → Si basta: Weah a fondo; los otros 3 casos, solo si sobra tiempo (BASES §0). Si piden los cuatro: cargar los otros 3 en modo lectura, sin ciclos nuevos.
2. **¿El tour guiado y el chat actuales de Sherpas se pueden ver en algún sitio (vídeo o capturas)?**
   → Si los enseñan: hacemos captura para la media página y ajustamos la frase diferenciadora. Si no: mantenemos el texto actual de BASES §3.
3. **¿Podemos señalar como hallazgo los datos incoherentes que encontremos en los JSON de los casos?**
   → Si es que sí: bloque "a revisar con vuestro asesor" en la hoja y pregunta del Q&A. Si no: usamos solo campos numéricos y no lo mencionamos.
4. **En el pitch, ¿podemos usar nuestro propio móvil y nuestra propia red, con algo en directo?**
   → Si es que sí: mensaje real con hotspot propio (BASES §20). Si no: la captura y el selector de días como camino principal.
5. **¿Hay pantalla o proyector para enseñar un móvil, o mejor traemos el vídeo?**
   → Si hay: duplicar la pantalla del móvil y ensayar el cable el jueves por la mañana. Si no: capturas grandes en diapositivas.
6. **¿Qué pesa más para vosotros, que la familia entienda y actúe o que el asesor llegue mejor preparado?**
   → Si es la familia: la hoja del asesor ocupa 20 s del pitch. Si es el asesor: la hoja sube a 30 s y abre la media página.
